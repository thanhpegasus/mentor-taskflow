## What this is

A 12-week structured mentoring program for a graduate software engineer, built around a real working application rather than isolated exercises. The mentee builds TaskFlow, a stripped-down ticketing/task management app — deliberately similar in spirit to the Jira board this program itself runs on. Backend in Java (Spring Boot), frontend in Next.js, source control and CI in GitHub, ticket tracking in Jira.

The project is scoped to be deep enough to teach real patterns — authentication, relational data modeling, REST API design, frontend state management, automated testing, CI/CD — without sprawling into "real business domain" complexity that would distract from the learning goals.

## Goals

By the end of week 12, the mentee should be able to:

 - Take a ticket from a written requirement through to deployed, tested code, independently

 - Apply standard engineering practices without prompting: Git branching, PR hygiene, code review etiquette, automated testing, CI pipeline awareness

 - Make and defend small architectural decisions (not just implement instructions)

 - Decompose a vague requirement into well-scoped, well-written tickets

 - Communicate technical work clearly — in code review, in documentation, and in a live demo
